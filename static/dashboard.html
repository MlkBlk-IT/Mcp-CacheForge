IcyCache Help

What is IcyCache

An async HTTP proxy that sits between your client and a local LLM. It normalizes the prompt, hashes it, and serves the stored answer instantly instead of burning CPU and tokens again.

Everything stays on this machine — no cloud, no paid API.

Request Flow

1. Normalize prompt → NFKD + lowercase + 1114 rules
2. Hash → SHA256 of model + messages + temperature
3. HIT → stored answer, zero generation
4. MISS → forward upstream, then store the answer

Reading the Metrics

HRHit RateRequests answered from cache. Higher is better — every point is CPU you didn't pay for.
TKTokens SavedPrompt + completion tokens skipped. This is the real money.
TK/sDecode SpeedUpstream generation speed, measured on real requests only.
%% SavedShare of total tokens that never had to be produced.
BYBypassRequests that skipped the cache entirely (non-deterministic or streaming).
