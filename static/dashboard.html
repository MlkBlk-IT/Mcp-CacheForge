In 5 steps

from the repo README

1 · Install

pip install icycache

2 · Start (from project folder): gateway :8080 + MCP layer

python tray.py

3 · Point your client at the gateway (prefix = upstream name)

base_url = http://127.0.0.1:8080/<upstream>/v1

Other ways to pick upstream: X-IcyCache-Upstream header, or upstream field in body, or config default.

4 · Connect MCP (3 transports active simultaneously)

python mcp_stdio.py
http://127.0.0.1:8081/sse
http://127.0.0.1:8084/mcp

5 · Verify: send the same request twice. The 2nd should appear as HIT in the live journal (Metrics view).

Request Flow

what the gateway does, in order
1
RoutingURL prefix /<upstream>/v1/…, else header, else body field, else config default
2
NormalizationNFKD → lowercase → Aho-Corasick → accents → punctuation → volatile date stripping
3
Cache KeySHA-256 of normalized content (+ upstream + endpoint)
4
HIT or MISSHIT: instant response without regeneration · MISS: forward to upstream then save
5
Real Tokensusage returned by upstream is authoritative, never estimated

Glossary

One-Shotnon-streaming or short requests — cacheable, high hit rate.
Agentic Streamgrowing context agent requests — structurally non-cacheable (each turn has unique hash).
Hit / Miss / Bypassserved from cache / forwarded to upstream / bypassed cache.
Tokens Savedreal usage from first call, replayed on each hit.
Speeduphow many times faster a HIT is vs a MISS.
Speedup Factorhow many times faster a HIT is vs a MISS (latency ratio).
Ice Cell Map 3Deach node = 1 cache entry; brighter = more hits.
